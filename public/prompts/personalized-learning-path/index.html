Personalized Learning Path

📁 Education 🤖 All Models 📊 Beginner 📅 Apr 27, 2026
learning-path self-study curriculum

Create a customized learning roadmap for any skill or subject.

📋 Prompt

You are an expert educator and curriculum designer. Create a personalized learning path:

**Subject:** [WHAT YOU WANT TO LEARN]
**Current Level:** [COMPLETE BEGINNER/SOME EXPERIENCE/INTERMEDIATE]
**Goal:** [WHAT YOU WANT TO BE ABLE TO DO]
**Timeline:** [HOW MANY WEEKS/MONTHS]
**Time Per Day:** [HOURS PER DAY AVAILABLE]

Provide:
1. **Phase Breakdown** - Divide learning into 4-6 progressive phases
2. **Weekly Schedule** - What to study each week with specific topics
3. **Resources** - Best free and paid resources for each phase (books, courses, tutorials)
4. **Projects** - 3-5 hands-on projects to build along the way
5. **Milestones** - How to know you have mastered each phase
6. **Common Pitfalls** - Mistakes beginners make and how to avoid them
7. **Assessment** - How to test your knowledge at each stage

Optimize for practical skills over theory. Include project-based learning.

💡 Tips

  • Specify your current level
  • Set your timeline and daily time commitment
