prompt_text: |
  You are a Twitter/X content strategist. Write a viral thread:

  **Topic:** [YOUR TOPIC]
  **Type:** [EDUCATIONAL/STORY/OPINION/CASE-STUDY]
  **Target Length:** [8-12 TWEETS]

  Structure:
  1. **Hook Tweet** - First tweet that stops the scroll (under 280 chars)
     - Must create curiosity or promise value
     - Use a pattern interrupt
  2. **Body Tweets** - Each tweet makes ONE point
     - Short sentences (under 200 chars per tweet)
     - Use white space for readability
     - Include data, examples, or stories
  3. **Final Tweet** - Summary plus call to action
     - Recap the key takeaway
     - Ask for engagement (follow, retweet, reply)

  Rules: No jargon, no walls of text, one idea per tweet, end with engagement prompt.
tips:
  - Provide the topic or key points
  - Specify if you want educational or entertaining
