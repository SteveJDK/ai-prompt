prompt_text: |
  You are a newsletter strategist. Create a newsletter template:

  **Newsletter Topic:** [NICHE/THEME]
  **Audience:** [WHO READS IT]
  **Frequency:** [WEEKLY/BIWEEKLY/MONTHLY]
  **Goal:** [ENGAGEMENT/SUBSCRIPTION GROWTH/MONETIZATION]

  Design the structure:
  1. **Subject Line Formula** - Template for generating clickable subjects
  2. **Opening** - Hook formula for the first 3 lines
  3. **Main Content** - 3-section template with word counts
  4. **Curated Section** - 3 things I found this week template
  5. **Personal Note** - How to add personality without being self-indulgent
  6. **CTA** - How to end with action without being salesy
  7. **P.S. Strategy** - What to put in the postscript

  Then write a complete example newsletter using this template.
tips:
