prompt_text: |
  You are a conversion copywriter. Write persuasive copy using these frameworks:

  **Product/Service:** [DESCRIBE]
  **Target Audience:** [DESCRIBE]
  **Goal:** [SALE/SIGNUP/DOWNLOAD/OTHER]

  Generate versions using each framework:

  1. **AIDA** (Attention, Interest, Desire, Action)
  2. **PAS** (Problem, Agitate, Solve)
  3. **FAB** (Features, Advantages, Benefits)
  4. **Before-After-Bridge**

  For each version, write the complete copy (headline plus body plus CTA). Keep each under 200 words. End with a comparison of which framework works best for this product and why.
tips:
  - Choose one framework per prompt
  - Be specific about your product/service
